# da-tableau-project

It is time to Recreate the SQL API Project using Tableau!

## Duration:
~ 1 day (project work + presentations)

## Main Objective:
- 5-10 minutes presentation
- min 2 dashboards (incorporated in a Tableau Story)

## Project Description:
Import the data in Tableau and recreate the visuals of your project's presentation. You can use whatever feature Tableau offers to tell your story. You need to create one tableau story including at least two dashboards.


### Optional: Follow your future/other ideas!
You might have had to prioritize your ideas during the project due to the time constraint. Now you have the chance to follow them up and maybe add to your presentation.

### Alternative:
It is also possible to recreate the **Muesli project** in Tableau, if you feel this would fit in well with the course.
